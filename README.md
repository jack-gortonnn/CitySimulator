# City Simulator

City Simulator is a finished city builder made in 2023 in Python.

It features 24 placeable and rotatable items which can contribute to an economy with maintenance costs, population and revenue.

Most of the code isn't great and this was made before I knew how to use sprite-sheets, so it's not the best, but it's fun to make small cities.
